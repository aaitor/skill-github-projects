# Repository presentation and demos

Follow the shared format in aaitor/oss-repo-template and `examples/demo-spec.json`. Keep the skill's existing name `github-project-board`; the repository is `skill-github-projects`.

Record real skill installation and Claude Code execution on a black 1280 × 640 terminal. The default demo reads a clearly labeled fictional backlog and stops at a proposed action. Do not substitute a mocked gh CLI or fabricated live API output. Never change boards, create issues, or post comments while recording or running CI. See `examples/README.md`.

Preserve dynamic field discovery, label scoping, and human-controlled In Definition/Done states. Keep private board data and credentials out of commits. Run `python3 scripts/check.py` for offline documentation and packaging validation.
