# Changelog

## v1.0 — 2026-10-29

First public release of **GitHub Projects Skill**.

- GitHub Projects v2 workflows through `gh`: discover board fields dynamically, review backlogs, select by priority/label, and coordinate progress updates and handoffs.
- Human review conventions: agents submit work as Ready; humans control In Definition and Done.
- Installation and board-setup guides, a practical walkthrough, CLI references, and GraphQL recipes.
- A real Claude Code demo reviewing a clearly labeled fictional backlog; it proposes work without changing GitHub.
- Shared banner/social artwork, community files, MIT license, and offline documentation/packaging checks.
- Repository renamed to `skill-github-projects`; `/github-project-board` remains compatible.
